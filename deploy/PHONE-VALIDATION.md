# 实际设备验证

本说明用于发布后的电脑、iPhone Safari 和 Android Chrome 验证。每项结果必须记录实际设备和时间。服务器测试、浏览器模拟以及通知服务返回成功均不能代替手机检查。

当前业务操作测试使用 `https://10.15.21.115/device-validation/`，应显示“模拟”环境。这里的两种耗材和数据库与正式库存独立。两部手机在此选择同一个“设备验证”对话，进行照片、录音、共享消息和业务确认测试。该临时页面不安装 PWA、不订阅通知。PWA 与通知使用正式入口 `https://10.15.21.115`，仅安排明确标记的测试通知。

## 连接与证书

记录电脑和两部手机的系统版本、浏览器版本及网络（校园网或学校 VPN）。访问 `http://10.15.21.115`，核对根证书 SHA-256 指纹：

```text
37:B7:8A:43:26:D2:3B:14:E1:34:17:20:13:81:F3:3D:74:E8:68:5A:03:13:B2:FF:3C:AA:2A:D0:09:88:02:FD
```

安装并信任证书后，确认 `https://10.15.21.115` 没有证书警告。iPhone 安装描述文件后，在“设置、通用、关于本机、证书信任设置”启用完全信任。Android 按设备的证书安装设置操作，再检查 Chrome。iPhone 从 Safari 添加至主屏幕，然后从主屏幕进入；Android 使用 Chrome 安装网站应用。

## 两部手机分别检查

1. 填写测试操作人姓名，进入同一个标明“设备验证”的共享对话。分别发送查询，确认电脑和另一部手机都能看到消息；重新进入后内容仍然存在。
2. 拍摄一张中文耗材清单并上传，核对名称、规格、数量、单位及来源。仅预览，不确认实际库存变更。
3. 允许麦克风，分别检查录音、停止、取消和识别状态。文字应先进入可编辑输入框；修改后发送一条查询，确认没有自动发送业务操作。
4. 在维护者准备的隔离测试数据库中，从另一台设备确认同一计划，重复确认后数量只变化一次。生产网站仅查询和预览，不改变实际库存。
5. 转至正式网站，授权通知，记录设备编号。维护者只向该设备安排标明“测试”的通知。关闭页面并锁定屏幕，检查实际通知；选择通知后，应进入校内提醒页面。分别记录通知出现时间、页面是否关闭、屏幕是否锁定，以及进入页面的结果。
6. 在学校 VPN 内重复连接检查。网络中断时，应显示断开或重新连接状态，恢复后可以继续原对话。
