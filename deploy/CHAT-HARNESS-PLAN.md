# 实验室 DSH 交付方案

当前交付方案使用定制 DSH 负责持续对话、工具调用、技能和官方本地语音识别，FastAPI 与 SQLite 负责全部业务规则、预览、确认和实际执行。教师只使用实验室专用网站。学校模型统一使用 `deepseek-pro` 的 `POST /v1/responses` 接口。

所有设备共享对话、任务和库存。查询直接执行，业务变更先预览并确认一次。模型只能查询、处理附件、生成预览、执行隔离的临时分析和导出结果，无法确认执行。方案使用 IP SAN 证书及实验室自管 CA；设备证书信任、校园网和 VPN 访问、录音及后台通知分别通过实际检查确认。

本方案取代此前的 HTTP 限制、设备之间的聊天隔离及禁止临时程序分析等安排。教师说明参见 [TEACHER-GUIDE.md](TEACHER-GUIDE.md)，版本固定、服务配置、备份和恢复参见 [README.md](README.md)。每次部署的提交编号和实际验证结果记录在对应日期的部署文件中。

附件库存尚未经教师核对。实物库存确认、试剂系统实际接入和真实平面图制作不属于本次完成条件，后两项保留扩展接口。实际设备检查未完成时不得宣称最终交付已经完成。
